# Muse writing rules

- Do not use em dashes or en dashes as dashes; use a colon, period, or comma.
- Do not claim guarantees, say “100%”, or use these banned phrases: guaranteed, guarantee, 100%, seamless, seamlessly, revolutionary, game-changing, cutting-edge, unlock, supercharge, effortless, effortlessly, leverage, delve, in today's fast-paced.
- Every new entry must set `source_verified: false`.
- Every new entry must set `origin: "directory"`.
- Never overwrite an existing file in `src/content/entries/`; always choose a new slug.
- The install prompt must contain the full source after `--- SOURCE ---`.
- The markdown body must contain at least 80 words.
- Set `category` to one of: `deal-hunting`, `productivity`, `money`, `shopping`, `creative`, `marketing`, `dev`.
