# Lane H: redesign as a plain shadcn directory

REASONING: high

## Objective
Replace the "Patch Library" visual world with a plain directory in the shadcn vocabulary, structured like grokbot.dev's marketplace. Every route, every content field, every copy string in `docs/COPY.md`, and every SEO artifact from lane F (canonical host, titles, descriptions, OG tags, JSON-LD, vercel.json, sitemap filter) stays. Only the presentation changes.

Read first: `PRODUCT.md` (Brand Commitments), `.impeccable/surfaces/src-pages-index-astro.md` (the direction contract; build exactly that), `docs/COPY.md`, `src/layouts/Base.astro`, every file in `src/components/` and `src/pages/`, `src/styles/global.css`, `src/lib/{categories,bank}.ts`, `src/content.config.ts`, `package.json`, `astro.config.mjs`.

Base: `body { @apply bg-background text-foreground font-sans antialiased; }`, `* { @apply border-border; }`, `::selection` uses primary and primary-foreground, `:focus-visible` uses `outline-2 outline-ring outline-offset-2`. Body text 16px/1.6. `html { color-scheme: light dark }` toggled with the class. Theme: an inline script in `Base.astro` `<head>` (before paint) reads `localStorage.theme`, else `prefers-color-scheme`, and sets `document.documentElement.classList.toggle('dark', ...)`. The toggle button flips it and stores it. Keep `theme-color` meta in sync (`#ffffff` light, `#09090b` dark) via the same script.
